# Source provenance

Imported machine source from the shared package `oldsun-0.20-share`
(Oldsun version 0.20).

Author: sandison, identified by the repository owner. Instrument authorship
credit belongs to sandison.

The package's guide states the MIT license but carried no LICENSE file or
copyright line; [LICENSE](LICENSE) records it under the author's name. The
package also states that it holds no firmware, OS image or files taken from
the OP-XY.

The initial commit preserves the package's files byte for byte: `oldsun/` at
the repository root, `colour/`, `init-preset/`, `oldsun-screen.png`, and the
package's top-level `README.md` as [GUIDE.md](GUIDE.md). SHA-256 of the
imported files, as shipped:

The demo recordings (`demos/`) remain outside this source repository. The
package's guide mentions a `presets/` folder that was not in the package; the
twelve presets in `definition.json` are part of the imported machine source.

Later commits add the repository files generated by the SDK's
`sdk.py new --repository` (AGENTS.md, CI workflow, .gitignore, the sound check
in `tests/`), this file and LICENSE, and adjust README.md's paths for the
root-level layout. The machine's code, metadata and artwork are unchanged.
